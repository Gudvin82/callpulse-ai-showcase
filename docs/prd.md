# Product Requirements (Showcase)

## Roles

- `Admin`: configuration, integrations, global controls.
- `Supervisor`: analytics, QA review, coaching actions.
- `Manager`: call handling, lead follow-up in CRM stages.

## Primary use cases

- Upload or ingest call records from telephony and process automatically.
- Review call cards with outcome, risk and concrete next actions.
- Track lead movement through CRM stages.
- Monitor AI/voice usage and environment health.

## User stories

- As a supervisor, I want to see the main issue of each call quickly, so I can coach my team without reading full transcripts.
- As a manager, I want each lead to have clear follow-up status, so no contact is lost.
- As an admin, I want to validate integrations and diagnostics, so I can operate the platform predictably.

## Scope v1 (public showcase)

- Safe mock API and sample payloads.
- Product architecture and API overview documentation.
- Demo data for calls/leads and sales overview.

## Out of scope (public)

- Production customer data.
- Commercial private algorithms.
- Full internal deployment scripts and infrastructure secrets.
